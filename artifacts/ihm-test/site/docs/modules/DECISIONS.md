# Decisions (ihm-web)

The standing decisions. Code comments cite them by number (`DEC-n`); a number never changes meaning. Where a module doc and this
file disagree, fix the doc. Each row: decision as it stands | why.

## Open questions
Replit test hosting retains the original site and Payload authentication. Uploads use private App Storage objects
served through Payload access controls, not ephemeral disk. Live payments, student portal embeds, email delivery,
tracking, and indexing are disabled. The admin gate also protects the first-user API.
This prevents the test copy from contacting live systems or exposing private application files.
1. Are staff emails public? (`staff.email` is staff-read until decided.)
2. Production storage for `media` and `documents`: persistent disk or a cloud storage adapter.
3. Production rate-limit store (DEC-54).
4. `/school-of-american-education/` and `/school-of-global-health/` (DEC-36): keep them served by the web server in front of Next, or rebuild them here like the School of Social Work.
5. PayWay offers no status lookup used by `reconcilePending`; pending PayWay rows rely on the notification.
